# advanced-cpp-course

ITMO Master: Advanced C++ Course for Game Development

## Labs

- **Hammurabi** is a turn-based console game about managing a city. Each round, the player trades land and decides how much grain to plant and how much to keep for food.
- **CustomArray** implements a generic dynamic array. It grows its own storage, manages element lifetimes, and provides forward and reverse iterators.
- **QuickSort** implements quicksort with a custom comparison function and median-of-three pivot selection. A second variant uses insertion sort for small ranges.
- **CustomAllocator** implements a hybrid memory allocator. Small requests use fixed-size blocks, medium requests use an allocator that merges adjacent free blocks, and large requests go directly to the operating system.
